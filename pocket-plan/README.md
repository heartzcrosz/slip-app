# Pocket Plan

แอปบันทึกค่าใช้จ่ายรายวันจากสลีป และวางงบรายเดือน ใช้บน iPhone ได้แบบแอป (ติดตั้งผ่าน Safari)

## ติดตั้งบน iPhone
1. เปิดลิงก์ของแอปใน **Safari**
2. กดปุ่ม **แชร์** (สี่เหลี่ยมมีลูกศรขึ้น) → **เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)**
3. เปิด **Open as Web App** ไว้ แล้วกด **เพิ่ม**

## ข้อมูลของคุณ
- ข้อมูลเก็บไว้**ในโทรศัพท์เครื่องนี้เท่านั้น** ไม่มีข้อมูลใดถูกส่งขึ้น GitHub หรือเซิร์ฟเวอร์
- สำรองข้อมูล: **กดค้างที่โลโก้แมวมุมซ้ายบน** → ส่งออกข้อมูลทั้งหมด (.csv) → บันทึกลงแอปไฟล์
- ย้ายเครื่อง/กู้ข้อมูล: กดค้างที่โลโก้ → นำเข้าข้อมูลทั้งหมด → เลือกไฟล์ที่สำรองไว้

## ไฟล์
- `index.html` แอปทั้งหมด (สลีปรายวัน + งบรายเดือน)
- `manifest.webmanifest`, `sw.js` ทำให้ติดตั้งเป็นแอปและเปิดได้แม้ออฟไลน์
- `icons/` ไอคอนแอป
